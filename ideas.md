# EXACT - Brainstorm de Design

## Contexto
Site imobiliário de alto padrão com foco em gestão inteligente de imóveis. Design dark/luxo baseado na referência visual fornecida pelo usuário, com nome "EXACT" em SF Pro Rounded com espaçamento elegante.

---

## Abordagem 1: Minimalismo Contemporâneo Escuro
**Probabilidade: 0.08**

### Design Movement
Minimalismo contemporâneo com influências do design suíço modernista, combinado com a estética tech-forward do design corporativo atual.

### Core Principles
1. **Espaço negativo como protagonista** - Amplos espaços em branco/preto para criar respiração visual
2. **Tipografia como elemento estrutural** - SF Pro Rounded como destaque principal, hierarquia clara através de peso e tamanho
3. **Contraste extremo** - Fundo muito escuro (quase preto) com textos e elementos em branco puro
4. **Minimalismo funcional** - Apenas elementos essenciais, sem decoração supérflua

### Color Philosophy
- **Fundo primário:** #0a0a0a (preto profundo, quase absoluto)
- **Textos principais:** #ffffff (branco puro para máximo contraste)
- **Acentos:** Ouro/dourado sutil (#d4af37) para elementos premium e CTAs
- **Secundários:** Cinzas neutros (#404040, #606060) para hierarquia
- **Raciocínio:** Elegância através da simplicidade; o ouro transmite luxo sem ser excessivo

### Layout Paradigm
- Seções full-width com padding generoso
- Hero com imagem de fundo com overlay escuro + texto sobreposto (como na referência)
- Grid assimétrico: cards de imóveis em 2-3 colunas com tamanhos variados
- Navegação fixa minimalista no topo
- Seções separadas por espaço em branco, não por linhas

### Signature Elements
1. **Linhas verticais sutis** - Divisores elegantes entre seções
2. **Tipografia em camadas** - Títulos em SF Pro Rounded Bold, subtítulos em SF Pro Rounded Medium
3. **Cards com borda sutil** - Apenas 1px de borda em cinza escuro para definição

### Interaction Philosophy
- Hover effects suaves: mudança de cor do ouro para branco
- Transições de 300ms em todos os elementos interativos
- Botões com background ouro e texto preto ao hover
- Fade-in suave ao scroll

### Animation
- Fade-in de elementos ao entrar na viewport (300ms)
- Hover: mudança de cor com transição suave (200ms)
- Botões: escala leve (1.02x) ao hover
- Scroll: parallax sutil em imagens de fundo

### Typography System
- **Display:** SF Pro Rounded Bold (48-64px) para títulos principais
- **Heading:** SF Pro Rounded Semibold (32-40px) para seções
- **Body:** SF Pro Rounded Regular (16px) para textos principais
- **Caption:** SF Pro Rounded Light (12-14px) para informações secundárias
- **Hierarquia:** Peso e tamanho como únicos diferenciadores

## Abordagem 2: Luxo Moderno com Textura
**Probabilidade: 0.07**

### Design Movement
Art Deco contemporâneo mesclado com modernismo escandinavo, com influências de design de interiores de luxo.

### Core Principles
1. **Texturas e profundidade** - Gradientes sutis, ruído, e efeitos de vidro fosco
2. **Geometria como ornamentação** - Formas abstratas e padrões geométricos elegantes
3. **Luxo através de refinamento** - Detalhes sofisticados em cada componente
4. **Movimento elegante** - Animações que sugerem fluidez e sofisticação

### Color Philosophy
- **Fundo primário:** #1a1a2e (azul-escuro muito profundo)
- **Acentos primários:** #c9a961 (ouro envelhecido, mais sofisticado)
- **Acentos secundários:** #e8d4b8 (bege quente para contraste)
- **Textos:** #f5f5f5 (branco quente, não puro)
- **Raciocínio:** Paleta inspirada em interiores de luxo; ouro envelhecido transmite herança e sofisticação

### Layout Paradigm
- Seções com fundo em gradiente sutil (vertical e horizontal)
- Hero com imagem de fundo + overlay com gradiente semi-transparente
- Padrão geométrico sutil como fundo em seções alternadas
- Grid de imóveis com cards que têm borda dourada sutil
- Navegação com efeito de vidro fosco (glassmorphism)

### Signature Elements
1. **Padrão geométrico abstrato** - Triângulos/linhas sutis em fundo
2. **Cards com borda dourada** - Moldura elegante em ouro envelhecido
3. **Efeito glassmorphism** - Componentes com backdrop blur e borda sutil

### Interaction Philosophy
- Hover: borda dourada se intensifica, card levanta com sombra
- Cliques: ripple effect em ouro
- Transições: 400ms para movimento mais elegante
- Botões: background gradiente ao hover

### Animation
- Entrada de cards com slide + fade (400ms)
- Hover: elevação com sombra dourada (300ms)
- Scroll: parallax em padrões geométricos
- Pulse sutil em elementos destacados

### Typography System
- **Display:** Playfair Display Bold (56-72px) para títulos principais
- **Heading:** Playfair Display Semibold (36-44px) para seções
- **Body:** Lato Regular (16px) para textos principais
- **Caption:** Lato Light (12-14px) para informações secundárias
- **Hierarquia:** Combinação de peso, tamanho e cor (ouro para destaque)

## Abordagem 3: Brutalism Digital Sofisticado
**Probabilidade: 0.09**

### Design Movement
Brutalism digital com influências de design industrial e arquitetura contemporânea, mas refinado e sofisticado.

### Core Principles
1. **Estrutura exposta** - Grid visível, linhas estruturais evidentes
2. **Materiais digitais** - Uso de cores sólidas, sem gradientes excessivos
3. **Tipografia como estrutura** - Fontes grandes e ousadas definem o layout
4. **Assimetria intencional** - Layouts não-centrados, composição dinâmica

### Color Philosophy
- **Fundo primário:** #0d0d0d (preto com leve tom quente)
- **Acentos primários:** #ff6b35 (laranja queimado para energia)
- **Acentos secundários:** #004e89 (azul profundo para contraste)
- **Textos:** #ffffff (branco puro)
- **Raciocínio:** Cores vibrantes contra fundo escuro criam impacto; laranja transmite inovação e energia

### Layout Paradigm
- Grid explícito com linhas visíveis
- Hero com imagem grande + texto sobreposto com fundo semi-transparente
- Cards de imóveis em layout assimétrico (diferentes tamanhos)
- Navegação com fundo sólido e linhas estruturais
- Seções com divisores visuais claros (linhas ou mudanças de fundo)

### Signature Elements
1. **Grid estrutural visível** - Linhas que definem o layout
2. **Tipografia ousada** - Títulos muito grandes e pesados
3. **Blocos de cor sólida** - Acentos em laranja ou azul como molduras

### Interaction Philosophy
- Hover: mudança de cor para laranja ou azul
- Cliques: inversão de cores (fundo vira laranja, texto vira preto)
- Transições: 250ms rápidas e diretas
- Botões: bordas grossas que se transformam ao hover

### Animation
- Entrada com slide lateral (300ms)
- Hover: mudança de cor com transição rápida (200ms)
- Scroll: movimento de blocos de cor
- Pulse em elementos principais

### Typography System
- **Display:** Courier Prime Bold (64-80px) para títulos principais
- **Heading:** Courier Prime Bold (40-48px) para seções
- **Body:** IBM Plex Mono Regular (16px) para textos principais
- **Caption:** IBM Plex Mono Light (12-14px) para informações secundárias
- **Hierarquia:** Tamanho extremo e cor como diferenciadores

---

## Decisão Final
**Será escolhida a Abordagem 1: Minimalismo Contemporâneo Escuro** por melhor se alinhar com:
- A referência visual fornecida (dark, limpo, elegante)
- O nome "EXACT" que sugere precisão e minimalismo
- A estética de imobiliária de alto padrão (sofisticação através da simplicidade)
- A tipografia SF Pro Rounded que funciona perfeitamente com minimalismo
